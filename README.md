# 🚀 Sales Intelligence System

## Project Overview
End-to-end ML system for sales forecasting, route optimization, and AI-powered business insights for Solutech Limited.

## 🎯 Business Problem
Field sales teams in Kenya need:
- Accurate sales forecasting
- Optimized delivery routes
- Real-time business insights
- Data-driven decision making

## 🛠️ Tech Stack
- **ML/AI:** Python, scikit-learn, TensorFlow
- **GenAI:** Google Vertex AI
- **API:** FastAPI
- **Deployment:** Docker, GCP
- **MLOps:** MLflow, Vertex AI Pipelines
- **Visualization:** Streamlit, Plotly

## 📁 Project Structure

## 🚀 Quick Start

### Prerequisites
- Python 3.9+
- Docker
- Google Cloud account

### Installation
```bash
# Clone repository
git clone https://github.com/yourusername/sales-intelligence-system.git
cd sales-intelligence-system

# Create virtual environment
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt
```
